Connect to GitHub

Paste your GitHub token once. After that, Publish to GitHub updates the live site directly, with no download or upload.

Not ticked: the token is forgotten when you close this browser tab. Tick it only on your own computer.

  1. On github.com, go to Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Repository access: Only select repositories → choose this site's repository.
  3. Permissions → Repository permissions → Contents: Read and write.
  4. Generate, copy the token, and paste it above. Never share it in chats or emails.
